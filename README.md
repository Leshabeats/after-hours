# After Hours

Ночная доска миссий по живому опенсорсу. Жги токены на issue и PR из стека, которым пользуешься: Vite, TanStack, Tailwind, React, Zod.

Ночь может выбрать цель сама, можно взять список, можно вставить свой GitHub URL. Журнал живёт только в браузере.

## Запуск

Нужен Node 22+.

```bash
cp .env.example .env
npm install
npm run dev
```

Открой [http://127.0.0.1:5173](http://127.0.0.1:5173).

| Команда | Что делает |
| --- | --- |
| `npm run dev` | dev-сервер на `:5173` |
| `npm run build` | production-сборка |
| `npm run preview` | собранное приложение на `:4173` |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | тесты классификации и парсера GitHub-ссылок |

## Переменные

Ни одна не обязательна.

- `GITHUB_TOKEN` — живой каталог с GitHub. Без токена приложение быстро упрётся в rate limit и покажет зашитый seed.
- `XAI_API_KEY` — кнопка «Разбор ночи» на карточке миссии. Без ключа разбор недоступен, остальное работает.

## Что это не делает

Нет аккаунтов, нет общей базы, нет деплоя из коробки. Журнал — `localStorage` на этом устройстве.

Прототип собран в Grok App Builder и вычищен в обычный TanStack Start репозиторий.
